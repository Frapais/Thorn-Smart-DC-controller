# Thorn-Smart-DC-controller
Thorn is a compact dual MOSFET control module, part of the SprigStack ecosystem. It lets an ESP32 (Sprig-C3) or other microcontroller switch high-current DC loads up to 10A each, from 5–30V. Ideal for LEDs, motors, fans, or smart DIY automation. Open-source hardware for makers and tinkerers.
